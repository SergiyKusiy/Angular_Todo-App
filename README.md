# Angular Todo App

A clean, modern Todo application built with Angular 17+.

## Features

- Add, edit, delete todos
- Toggle completion status
- Filter by All / Active / Completed
- Clear all completed at once
- Error notifications with auto-close

## Tech Stack

- Angular 17+ (Signals, computed, inject)
- TypeScript
- SCSS (BEM, variables, mixins)
- JSONPlaceholder API
